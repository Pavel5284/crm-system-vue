# @crm/validation

Единый дом правил валидации полей: чистые предикаты и zod-фабрики
с инжектом сообщений. Без Vue/Nuxt/i18n: строки готовит вызывающая
сторона (host — через `t()`, пакеты — через labels).

## Состав

- Предикаты: `isValidEmailFormat` (только латиница — зеркало бэкенд-константы
  `ASCII_EMAIL_PATTERN` в `@app/shared`, править оба места 1-в-1),
  `containsControlChars`.
- Фабрики (`emailRule`, `nameRule`, `phoneRule`, `textRule`): принимают
  сообщения + опции (`required`, `maxLength`), возвращают zod-схемы.
- `toFieldValidator`: адаптер zod-схемы к TanStack Form (первая ошибка
  строкой, валидно — `undefined`).

## Потребители

- `app/schemas/*` (host): тонкая проводка `t()` в фабрики.
- `@crm/customer-form`: проводка labels в фабрики.
- Инлайн-гарды (канбан и т.п.): предикаты напрямую.

Зависимости: `zod`, `@crm/ui-kit` (проверка формата телефона).
Бэкенд — отдельным зеркалом (другой проект, кросс-импорт невозможен).
